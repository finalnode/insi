# C-Dur-Tonleiter
@difficulty:einfach

Spiele eine vollständige C-Dur-Tonleiter aufwärts.

- Spiele `C4`, `D4`, `E4`, `F4`, `G4`, `A4`, `B4` und `C5`.
- Jeder Ton dauert einen Beat.
- Speichere die Noten in einer Liste und verwende eine Schleife.

Starte den Test mit `run(check="tonleiter-c-dur")`.
