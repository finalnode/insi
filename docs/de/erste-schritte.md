# Erste Schritte mit in:si

in:si ist eine lokale Lernumgebung. Lerntexte, Aufgaben, Projekte und Lernstand
liegen als nachvollziehbare Dateien auf dem Gerät oder einem bewusst gewählten
Datenträger. Für die normalen Lernabläufe ist nach der Einrichtung kein Konto
und keine dauerhafte Internetverbindung nötig.

## 1. Kurs auswählen

Beim ersten Start zeigt in:si die vorhandenen Kurse. Ein Kurs kann lokal, als
portables Kurs-ZIP oder über ein bewusst ausgewähltes Repository eingerichtet
werden. Vor einem Import zeigt in:si Herkunft und Sicherheitsgrenzen an.

Der Kursordner enthält sowohl die installierten Kursinformationen als auch den
persönlichen Workspace. Veröffentlichte Inhalte und persönliche Lösungen sind
getrennt, damit ein Kursupdate keine Schülerarbeit überschreibt.

## 2. Lernen

Unter **Skript** stehen die Kapitel des ausgewählten Kurses. Markierte
Codeblöcke lassen sich kopieren oder – wenn die Sandbox bereit ist – direkt
ausführen. Normale Textbeispiele werden niemals allein durch das Öffnen eines
Kapitels gestartet.

Unter **Aufgaben** stehen Aufgabenstellung, Hinweise, Editor und Trainerfeedback
zusammen. Speichern und Ausführen sind getrennte Aktionen. Der Lernstand wird
lokal im Kursordner gespeichert.

## 3. Eigene Projekte

Unter **Meine Projekte** entstehen längere Programme mit Quellcode,
Dokumentation und optionalen Pyxel-Ressourcen. Vor einem integrierten Start legt
in:si einen begrenzten lokalen Projektstand an. Diese Stände sind noch keine
vollständige Wiederherstellungsoberfläche; die folgt laut Roadmap in 0.8.

## 4. Integrierter Start und externe IDE

Ein integrierter Start wird nur angeboten, wenn der Betriebssystemadapter einen
echten Selbsttest besteht. Ohne funktionsfähige Sandbox fällt in:si nicht auf
einen ungeschützten Prozess zurück.

**In IDE öffnen** startet dagegen Thonny, VS Code oder eine konfigurierte IDE
mit den normalen Rechten des Benutzerkontos. Das ist ein bewusster Wechsel aus
der in:si-Sandbox.

## 5. Dateien und Lernstand

Der aktive Kursordner ist im Footer sichtbar und lässt sich öffnen. Persönliche
Lösungen, Projekte, Notizen und Lernstand sollten wie andere wichtige
Unterrichtsdateien regelmäßig gesichert werden. Auf synchronisierten Laufwerken
soll derselbe Kurs nicht gleichzeitig auf mehreren Geräten bearbeitet werden.
